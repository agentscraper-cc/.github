# AgentScraper

Scheduled web collection for AI workflows, built to be boring.

- **Website:** [agentscraper.cc](https://agentscraper.cc)
- **Blog:** [agentscraper.cc/blog](https://agentscraper.cc/blog) · **Guides:** [agentscraper.cc/guides](https://agentscraper.cc/guides)
- **Docs:** [agentscraper.cc/docs](https://agentscraper.cc/docs)
- **CLI:** [`agentscraper`](https://github.com/agentscraper-cc/cli), live web pages as Markdown from your terminal ([docs](https://agentscraper.cc/docs/cli), [npm](https://www.npmjs.com/package/@agentscraper-cc/cli))

```bash
npx @agentscraper-cc/cli fetch https://example.com -o text
```
